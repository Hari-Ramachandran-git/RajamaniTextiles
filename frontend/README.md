# Rajamani Textiles Frontend

Standalone React + Vite storefront for **RAJAMANI TEXTILES, Madurai** using `src/data/products.json` and `src/mock-store.js`.

```sh
npm ci
npm start
```

No API, backend or environment variables are needed. The frontend runs completely self-contained with full catalogue, product detail pages, bag, wishlist, and simulated checkout.
