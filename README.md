# Rajamani Textiles — Madurai

A modern React & Vite storefront for **RAJAMANI TEXTILES, Madurai** featuring wholesale & retail home linens, bedsheets, towels, Ilavam Panju beds & pillows, baby bedding, function shawls, innerwear, door & window screens, bedspreads, and bedcovers.

The frontend runs independently with local mock data. No backend, API keys, or environment variables are required.

## Run locally

```sh
cd frontend
npm install
npm run start
```

Open **http://localhost:5173**. From the repository root you can also run `npm run dev`.

## Products Handled
1. **Bedsheets** — Pure cotton single, double and king size bedsheets with matching pillow covers.
2. **Towels** —  Pure cotton honeycomb waffle towels, Turkey  bath towels, hand & face sets.
3. **Pillows** — 100% natural South Indian Ilavam Panju (silk cotton) pillows and hotel cloud microfiber pillows.
4. **Beds / Mattresses** — Handcrafted Madurai Ilavam Panju cotton mattresses and foldable hostel beds.
5. **Baby Section** — 3-in-1 foldable travel beds, waterproof breathable quick dry sheets, umbrella mosquito nets, newborn luxury gift hampers, and sleeping nests.
6. **Function Shawls** — Royal gold zari Ponnada felicitation shawls and ceremonial wedding gift shawls.
7. **Inner Wears** — 100% super combed cotton vests and breathable stretch trunks/briefs.
8. **Door & Window Screens** — 7ft door screen curtains and 5ft window screen drapes with steel eyelet rings.
9. **Bed Spreads** — Traditional heavy Madurai handloom jacquard bedspreads and chenille floral spreads.
10. **Bedcovers** — All-season ultrasonic quilted bedcovers and 100% waterproof elastic fitted protectors.
